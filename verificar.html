🔎 Verificação antes de publicar

Esta página confere se os arquivos e o ambiente estão prontos. Ela não muda nada — só verifica.

O que fazer com o resultado:
• Tudo verde → pode publicar.
• Vermelho no HTTPS → a câmera não vai funcionar. Publique pelo GitHub Pages (que é https), não abra pelo arquivo local.
• Vermelho num arquivo → falta subir aquele arquivo para o repositório.
